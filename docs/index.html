The problem

Nobody's watching.

How it works

Three steps to production safety

1

Baseline

Snapshot your known-good schema. Takes one command and outputs a versioned JSON file you commit to your repo.

2

Watch

Run drift detection on a schedule or continuously. Get instant alerts when something changes unexpectedly.

3

Operate

Validate backups, generate safe migrations, and roll them out across your entire fleet with one command.

Fleet operations

One database is monitoring.
A hundred is a fleet.

Per-tenant SQLite is exploding — and nobody has tooling for the day you're running 300 of them.

  • 🔎
    Auto-discovery Query a Turso org or D1 account and get every database registered instantly.
  • ⚡
    Parallel drift detection "309 ok, 1 drifted" across the whole fleet in seconds. Exit 1 gates CI.
  • 🚀
    Staged rollouts Apply one migration across the fleet, halting at the first failure so a bad change can't cascade.
  • 🛡️
    Canary deploys Apply to the first N databases, verify, then continue — with per-database backups and rollback.
