Lock doctor — "database is locked"

Diagnose lock contention

SQLite has a single writer, so SQLITE_BUSY is the most common production failure. Pick a database to see its WAL / busy_timeout / locking-mode config, whether a writer holds the lock right now, and the exact fix.

Autopilot — DBA self-driving

See the maintenance plan

Autopilot derives the safe maintenance and indexing actions a DBA would take — refresh planner stats, reclaim fragmented space, add missing foreign-key indexes — and explains each in plain language. This is a read-only preview; apply it with litescope autopilot <db> --apply (it snapshots first, so every run is one restore from undo).

Backups — point-in-time snapshots

Snapshot & restore

Snapshots are consistent VACUUM INTO copies (safe even under WAL), integrity-checked on write. Restore overwrites the live file — but a safety snapshot of the current state is taken first, so a restore is itself one snapshot from undo.
